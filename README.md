# React Social Media App

A simple and responsive Social Media Web Application built using React.js. This project demonstrates React concepts such as Components, Props, Context API, and the `useContext` Hook.

## 🚀 Features

- Create and display social media posts
- Manage application state using Context API
- Reusable React components
- Responsive user interface
- Organize posts and application data
- Built with modern JavaScript and React.js

## 🛠️ Technologies Used

- **Frontend:** React.js, JavaScript, HTML5, CSS3
- **State Management:** React Context API, useContext Hook
- **Development Tools:** Visual Studio Code, npm, Git, GitHub

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Jaganathanjagan/React_Social_Media.git
   ```

2. Navigate to the project directory:

   ```bash
   cd React_Social_Media
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, usually `http://localhost:5173`.
